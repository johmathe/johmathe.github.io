NeurIPS 2026

: Selective \(G\)-Bispectra Made Practical

Fast, exact symmetry invariants for PyTorch.

Johan Mathe, Adele Lantow, Simon Mataigne and Nina Miolane · Paper · Code

We built bispectrum, a PyTorch library that turns signals into features with built-in invariance to a chosen symmetry. It uses the \(G\)-bispectrum to capture relationships across frequencies that survive transformations such as rotations or translations. A selective algorithm and GPU optimizations keep it cheap, and the result trades a little accuracy for a lot of speed while keeping completeness guarantees. On rotated Spherical MNIST our model reaches 95.8%, 0.3 points behind a spherical CNN and an e3nn tensor-product network, with 4 and 364 times lower latency on a modern GPU. Its features are provably complete for generic signals on the library's finite groups and on the disk, and conjectured complete on the sphere.

Invariance in classifiers

The top model in the figure is a small CNN that reads the sphere as a 64 × 128 image. It is right on 13.4% of rotated test digits, close to chance, and it reads the 2 on its side as an 8. Nothing in its weights says that a turned 2 is still a 2. There are three standard ways to put that in.

Data augmentation. The network trains on rotated copies of every digit. With online augmentation, each step draws new poses, so the number of training steps can stay the same. The learned invariance is approximate, and it holds for the poses and digits the network was shown.

Max pooling over poses. A group convolution applies each filter in every pose of a group \(G\), which adds an axis with one slot per pose. Transforming the input permutes that axis and can also move the feature maps in space. A max over the axis removes the dependence on the permutation, but the spatial coordinates can still transform, so a fully invariant model also pools over space. The max keeps one response out of \(|G|\) and can map two different inputs to the same value.

Fourier magnitudes. On a periodic signal, a shift multiplies each Fourier coefficient \(c_k\) by a phase and leaves \(|c_k|\) alone, so the power spectrum \(|c_k|^2\) is invariant for free. On the sphere it is one energy per degree, or 16 numbers in the paper's setting. An MLP on them, the middle model, gives the same answer in every pose, and for this 2 the answer is a 3 (70%). It scores 77.7% on rotated digits. The invariance is exact and the model still falls short, because magnitudes record how much of the digit sits at each scale and nothing about how the pieces line up.

The bottom model uses the bispectrum, which is exactly invariant and also keeps the relations between frequencies that the power spectrum drops. The next section says what such a feature should keep and what it should forget, and builds the bispectrum on a periodic signal. The one after carries it to other groups and to the sphere.

The bispectrum and what it preserves

The bispectrum is a Fourier map that locks relative phases across triples of frequencies, capturing a signal's shape up to a shift.

Invariant and complete

The ideal invariant is a lossless summary with one thing deliberately lost, the symmetry of interest (for example a rotation). We write \(g \cdot x\) for a signal \(x\) transformed by an element \(g\) of a group \(G\). We call \(g\) the signal's pose, and the set of all its transformed copies its orbit. A map \(\beta\) is invariant if it is constant on orbits, and complete if it also tells orbits apart,

\[ \beta(x) = \beta(y) \iff y = g \cdot x \text{ for some } g \in G. \]

An invariant has to forget the pose, and a complete one forgets nothing else.

Shifting a periodic signal

Let's start with a straightforward symmetry, a shift of a periodic signal. The signal below is a mean plus four harmonics, each with a magnitude \(|c_k|\) and a phase \(\varphi_k\). Shifting it by \(s\) slides every harmonic by the same distance, so harmonic \(k\) turns its phase by \(ks\) and keeps its magnitude. Wrapping one period around a circle turns a shift into a 2D rotation, the group SO(2).

The power spectrum \(|c_k|^2\) gives us invariance by ignoring all phases, so a global shift leaves it unchanged. The catch is that dropping those phases loses the whole shape of the signal, since scrambling them produces a completely different curve with the same \(|c_k|^2\). If instead we keep relationships between frequencies where the global shift cancels out, we stay invariant without losing the shape.

Pairing two frequencies only cancels the shift when \(k_1 = k_2\), which gives \(|c_k|^2\) back, so the simplest nontrivial relationship couples three harmonics with \(k_1 + k_2 = k_3\). A shift turns \(\varphi_{k_1} + \varphi_{k_2} - \varphi_{k_3}\) by \(-(k_1 + k_2 - k_3)s = 0\), so the combination stays put. The bispectrum collects these triple products, one entry per pair of frequencies,

\[ \beta_{k_1, k_2} = c_{k_1}\, c_{k_2}\, \overline{c_{k_1 + k_2}}. \]

For this four-harmonic signal, nine bispectrum entries are nonzero (those with \(k_1 \le k_2\) and \(k_1 + k_2 \le 4\)), and they are more than enough to rebuild it. Starting from \(\beta_{0,0}\) and \(\beta_{0,1}\) for the mean and \(|c_1|\), each \(\beta_{1,k}\) recovers the next harmonic from the ones before it, leaving four entries unused. Nothing fixes the phase of the first harmonic, and choosing it chooses the shift, the one freedom an invariant should leave. For signals of this kind with no zero coefficient, two with the same bispectrum go through the same steps to the same shifted copies, so each is a shift of the other. That is completeness in the sense above.

Fold-out · skippableThe definition and the recovery, formally

A real signal of period \(2\pi\) with four harmonics is

\[ f(x) = c_0 + 2 \sum_{k=1}^{4} |c_k| \cos(kx + \varphi_k), \]

with Fourier coefficients \(c_k = |c_k|\, e^{i\varphi_k}\) in the sign convention of torch.fft. A shift by \(s\) acts as \(c_k \mapsto e^{-iks} c_k\). The bispectrum is defined from the triple correlation, the average product of the signal at three points,

\[ T(s_1, s_2) = \frac{1}{2\pi} \int_0^{2\pi} f(x)\, f(x + s_1)\, f(x + s_2)\, dx, \]

as its Fourier transform over both lags,

\[ \beta_{k_1, k_2} = \frac{1}{4\pi^2} \int_0^{2\pi} \!\! \int_0^{2\pi} T(s_1, s_2)\, e^{-i(k_1 s_1 + k_2 s_2)}\, ds_1\, ds_2 = c_{k_1}\, c_{k_2}\, \overline{c_{k_1 + k_2}}, \]

and under a shift it picks up \(e^{-i(k_1 + k_2 - (k_1 + k_2))s} = 1\) (Tukey, 1953). The row \(k_1 = 0\) is \(c_0 |c_k|^2\), so the bispectrum contains the power spectrum whenever \(c_0 \neq 0\).

The recovery reads \(c_0\) from \(\beta_{0,0} = c_0^3\) and \(|c_1|\) from \(\beta_{0,1} = c_0 |c_1|^2\), sets \(\arg c_1\) freely, and then takes \(c_{k+1} = \overline{\beta_{1,k} / (c_1 c_k)}\) for \(k = 1, 2, 3\), which needs every divisor to be nonzero.

Generalizing the bispectrum to more symmetries

The \(G\)-bispectrum generalizes the bispectrum to a group \(G\) by replacing ordinary frequencies with the group's own Fourier modes, capturing a signal's shape up to symmetries such as flips or 3D rotations.

The Fourier transform on a group

The periodic signal had a simple structure. A shift turned each coefficient by its own phase, and three phases cancelled when their frequencies added. The digits at the top live on a sphere, where a rotation mixes coefficients together instead of turning them one by one. Other symmetries need the Fourier transform of their own group, and the recipe still works once the phases become matrices. This chapter builds it for signals on a group first, then on the sphere, and then reconstructs a spherical signal from its invariants.

A signal on a group, such as the output of a group convolution, has one value \(f(g)\) per pose \(g \in G\) for each channel and pixel. Its Fourier coefficients are indexed by the group's irreducible representations, or irreps. An irrep is a map \(\rho\) from \(G\) to \(d_\rho \times d_\rho\) unitary matrices that respects composition, \(\rho(gh) = \rho(g)\, \rho(h)\), and that no change of basis splits into smaller blocks. The coefficient at \(\rho\) is the matrix

\[ \hat f(\rho) = \sum_{g \in G} f(g)\, \rho(g)^\dagger \;\in\; \mathbb{C}^{d_\rho \times d_\rho}. \]

Irreps play the role of frequencies. On the cyclic group \(C_n\) they are all \(1 \times 1\), \(\rho_k(g) = e^{2\pi i k g / n}\) for \(k = 0, \dots, n - 1\), and \(\hat f(\rho_k)\) is the \(k\)-th coefficient of the discrete Fourier transform, with the sign convention of torch.fft. When the group doesn't commute, as with the rotations of a cube or the turns and flips of a polygon, some irreps are matrices, and so are the coefficients. Shifting the signal by \(h\), so that \(f(g)\) becomes \(f(h^{-1} g)\), multiplies each coefficient on the right by \(\rho(h)^\dagger\), the matrix version of the phase \(e^{-iks}\).

Fold-out · skippableThe group Fourier transform, formally

Two properties of the DFT carry over. The transform is invertible, and since \(\sum_\rho d_\rho^2 = |G|\), it holds exactly as many numbers as the signal. And a shift becomes a multiplication. If \((h \cdot f)(g) = f(h^{-1} g)\), then

\[ \widehat{h \cdot f}(\rho) = \hat f(\rho)\, \rho(h)^\dagger. \]

For continuous groups such as SO(2) and SO(3), the sum becomes an integral and there are infinitely many irreps, so an implementation keeps those up to a cutoff. For a signal on a space that the group acts on, such as the sphere, the coefficients are vectors rather than square matrices.

The \(G\)-bispectrum

For the periodic signal, the phases cancel because frequencies add. The product \(c_{k_1} c_{k_2}\) turns by \(e^{-i(k_1 + k_2)s}\), exactly like \(c_{k_1 + k_2}\). With matrix coefficients, the product of two coefficients is a tensor product \(\hat f(\rho_1) \otimes \hat f(\rho_2)\), and a shift acts on it through \(\rho_1 \otimes \rho_2\). That representation is usually not irreducible, but a fixed unitary change of basis \(C_{\rho_1 \rho_2}\), the matrix of Clebsch–Gordan coefficients, splits it into irreps. This split takes the place of "frequencies add". The \(G\)-bispectrum pairs the tensor product with the conjugate coefficients at the irreps it contains. Writing \(C\) for \(C_{\rho_1 \rho_2}\),

\[ \beta_{\rho_1, \rho_2} = \big[\hat f(\rho_1) \otimes \hat f(\rho_2)\big]\, C \Big[\bigoplus_{\rho \in \rho_1 \otimes \rho_2} \hat f(\rho)^\dagger\Big]\, C^\dagger. \]

A shift turns the two factors in opposite directions, and they cancel as the phases did for the periodic signal. When every irrep is \(1 \times 1\), \(C = 1\) and the formula is the triple product again. Each block \(\beta_{\rho_1, \rho_2}\) is a \(d_{\rho_1} d_{\rho_2} \times d_{\rho_1} d_{\rho_2}\) matrix, so one block holds many scalar entries. The same recipe, with each group's irreps and Clebsch–Gordan matrices, gives every module of the library.

The \(G\)-bispectrum is invariant for every one of these groups. Kakarala (1992) proved that on a finite group it is also complete when every Fourier coefficient \(\hat f(\rho)\) is an invertible matrix. We call such signals generic. The exceptions form a set of measure zero, so a signal drawn from any distribution with a density is generic with probability one. For the periodic signal it means that no \(c_k\) is zero, which is what the recovery needed.

Fold-out · skippableThe \(G\)-bispectrum, formally

The Clebsch–Gordan matrix block-diagonalizes the tensor product,

\[ C_{\rho_1 \rho_2}^\dagger\, (\rho_1 \otimes \rho_2)(g)\, C_{\rho_1 \rho_2} = \bigoplus_{\rho \in \rho_1 \otimes \rho_2} \rho(g), \]

where an irrep that occurs several times in \(\rho_1 \otimes \rho_2\) appears that many times in the sum. Under a shift by \(h\), the tensor product is multiplied on the right by \((\rho_1 \otimes \rho_2)(h)^\dagger = C \big[\bigoplus \rho(h)^\dagger\big] C^\dagger\), the block-diagonal factor picks up \(\bigoplus \rho(h)\) on its left, and the two cancel in \(\beta_{\rho_1, \rho_2}\). As for the periodic signal, \(\beta\) is the Fourier transform, now on \(G \times G\), of the \(G\)-triple correlation \(T(g_1, g_2) = \sum_{g} f(g)\, f(g g_1)\, f(g g_2)\) (Kakarala, 1992).

Fold-out · skippableIrreps and Clebsch–Gordan coefficients on a polygon

The smallest groups with irreps larger than \(1 \times 1\) are the dihedral groups \(D_n\), the \(n\) turns and \(n\) flips of a regular \(n\)-gon. They are generated by a turn \(a\) and a flip \(x\) with \(x a x = a^{-1}\), so turning and then flipping is not the same as flipping and then turning. Two irreps of \(D_n\) are \(1 \times 1\) (four when \(n\) is even) and send each element to \(\pm 1\). The rest are \(2 \times 2\),

\[ \rho_k(a) = \begin{pmatrix} \cos \frac{2\pi k}{n} & -\sin \frac{2\pi k}{n} \\ \sin \frac{2\pi k}{n} & \cos \frac{2\pi k}{n} \end{pmatrix}, \qquad \rho_k(x) = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}, \qquad 0 < k < n/2. \]

These two matrices don't commute, so no change of basis diagonalizes both, and a shift mixes the columns of each \(2 \times 2\) coefficient. The tensor product \(\rho_i \otimes \rho_j\) of two \(2 \times 2\) irreps splits into \(\rho_{i+j} \oplus \rho_{i-j}\). Indices are read modulo \(n\) and up to sign, and a block whose index is a multiple of \(n/2\) splits further into two \(1 \times 1\) irreps. The Kronecker table of \(D_5\) collects these splits.

For the periodic signal each cell would hold the single frequency \(k_1 + k_2\). The Clebsch–Gordan matrix \(C_{\rho_1 \rho_2}\) is the change of basis that performs each split, and the \(G\)-bispectrum has one block per cell of the table. The block of \(E_1 \otimes E_1\) is a \(4 \times 4\) matrix, 16 scalar entries.

The sphere

Back to the digits on the sphere, whose symmetry group is SO(3). Its irreps are indexed by a degree \(\ell = 0, 1, 2, \dots\), and the basis functions are the spherical harmonics \(Y_\ell^m\), \(-\ell \le m \le \ell\). The \(2\ell + 1\) coefficients of degree \(\ell\) form a vector \(\mathbf F_\ell = (a_\ell^{-\ell}, \dots, a_\ell^{\ell})\), and a rotation \(R\) mixes them by a unitary matrix, the Wigner D-matrix \(D^\ell(R)\),

\[ \mathbf F_\ell \mapsto D^\ell(R)\, \mathbf F_\ell. \]

A rotation mixes the coefficients within a degree but never moves them into another degree, and \(D^\ell(R)\) is unitary, so the energy \(\|\mathbf F_\ell\|^2\) of each degree is invariant. These energies are the power spectrum on the sphere. Keeping degrees up to a band-limit \(L\) leaves \((L + 1)^2\) coefficients and \(L + 1\) energies, 16 at the paper's \(L = 15\). The spherical bispectrum follows the same recipe as before. It projects the product of two degrees onto a third with Clebsch–Gordan coefficients and pairs the result with that degree's coefficients,

\[ \beta_{\ell_1, \ell_2, \ell} = \sum_{m=-\ell}^{\ell} \; \sum_{m_1 + m_2 = m} C^{\ell m}_{\ell_1 m_1 \ell_2 m_2} \; a_{\ell_1}^{m_1}\, a_{\ell_2}^{m_2}\, \overline{a_\ell^{m}}, \]

one number for each triple of degrees with \(|\ell_1 - \ell_2| \le \ell \le \ell_1 + \ell_2\). Kakarala's theorem does not cover the sphere. The subset of these entries that the bottom model of the figure at the top reads, and what is known about its completeness, come below.

Fold-out · skippableInvariance on the sphere, and the quartic terms

The projected product \((\mathbf F_{\ell_1} \otimes \mathbf F_{\ell_2})|_\ell\) and \(\mathbf F_\ell\) transform by the same unitary \(D^\ell(R)\), so their inner product, \(\beta_{\ell_1, \ell_2, \ell}\), is invariant. The squared norm of the projected product, \(\|(\mathbf F_{\ell_1} \otimes \mathbf F_{\ell_2})|_\ell\|^2\), is invariant for the same reason. It is quartic in the coefficients, and the paper calls it a Clebsch–Gordan power coefficient. The construction below adds a few of them to the cubic entries.

Reconstructing a signal on the sphere

Invariance is easy to check by rotating the signal. Completeness, the claim that nothing but the pose is lost, can be tested by rebuilding a signal from its invariants alone. The figure takes the Earth's land mask in spherical harmonics up to degree 20, or 441 coefficients. Its power spectrum is 21 numbers, and random globes with the same 21, the sphere's version of the phase scramble, look nothing like the Earth. The subset of its bispectrum chosen the same way as the bottom model's has 638 values, sums of products of three or four coefficients. From those alone, a numerical solver rebuilds the land mask in a pose of its own. Rotated onto the original, the rebuilt coefficients match the original's to a relative error of about \(10^{-12}\), or 12 digits.

The tiles above the figure swap the Earth for a Spherical MNIST digit or a drawing of your own, at \(L = 12\), and the solver reruns live in the browser whenever the pen lifts. Very symmetric drawings, such as a dot or a centered ring, are unchanged by every rotation about some axis, so they are far from generic and the solver often fails on them.

Fold-out · skippableHow the solver chooses its answer

The solver runs from several random starts. It chooses among the candidates by how closely their invariants match the target's, with ties broken by a fixed order that does not depend on the target, and it never compares a candidate with the original. Only after the choice is the original used, to rotate the chosen globe onto it and to measure the error of its band-limited harmonic coefficients.

How selective bispectra reduce complexity

The full bispectrum grows quadratically with the size of the signal, which puts it out of reach on images and other modern data. Selective \(G\)-bispectra keep a linear number of entries, just enough to pin the signal down up to its symmetry.

The cost of the full bispectrum

Completeness comes at a price. The bispectrum has one entry per pair of frequencies, or per pair of irreps on a finite group, so a signal of \(|G|\) numbers has \(O(|G|^2)\) of them. Small signals hide the problem. A 32 × 32 image under cyclic shifts, the grid tile of the group figure, has 1,024 pixels and already 524,800 entries. A 256 × 256 image, modest by today's standards, has 65,536 pixels and 2,147,516,416 entries. At 8 bytes each that is about 17 GB, most of a 24 GB GPU, for a single image in a single forward pass.

Most of those entries are redundant, though. The shift figure rebuilt its signal from 5 of its 9 entries and never touched the other 4. What matters is choosing which entries to keep.

Selective \(G\)-bispectra on finite groups

On a periodic signal, the answer is the chain that the shift figure walked, \(\beta_{0,0}\), \(\beta_{0,1}\) and the row \(\beta_{1,k}\). For \(n\) samples it keeps \(n\) of the \(n(n+1)/2\) entries, which determine the signal up to a shift when no coefficient is zero (Giannakis, 1989), and every other entry can be recomputed from them. For the 256 × 256 image that is 65,536 numbers, half a megabyte instead of 17 GB.

Mataigne et al. (2024) carry this idea to any finite group. A breadth-first search over the table of tensor products, like the \(D_5\) table in the fold-out, picks \(O(|G|)\) scalar entries that still determine a generic signal. They call the result the selective \(G\)-bispectrum. For the 24 rotations of a cube it keeps 172 of the 576 scalars. The search runs on any finite group, and their completeness theorems cover the commutative, dihedral and octahedral groups.

The disk has a proof too. Under a rotation by \(\phi\), every coefficient \(a_{n,k}\) at angular order \(n\) turns by the same phase \(e^{in\phi}\), whatever its radial order \(k\). The selective disk bispectrum of Lantow and Miolane (2026) builds on this and is complete for images with \(a_{n,1} \neq 0\) at every retained angular order.

The sphere, degree by degree

The sphere needs its own construction. Its full bispectrum grows more slowly, as \(L^3\) entries for \((L + 1)^2\) coefficients, but each entry is a sum of Clebsch–Gordan terms. There is also no chain as simple as the ring's, because each degree brings \(2\ell + 1\) unknowns at once. The construction therefore goes degree by degree. Once the lower degrees are known, an entry \(\beta_{a, b, \ell}\) with \(a, b < \ell\) is linear in \(\overline{\mathbf F_\ell}\). Each degree keeps up to \(2\ell + 1\) of these, plus a few self-couplings \(\beta_{\ell, \ell, \ell'}\) and Clebsch–Gordan power coefficients, so that the linear system for \(\mathbf F_\ell\) has full rank. The result, the augmented selective spherical bispectrum, has \(\Theta(L^2)\) entries, on the scale of the signal itself, and costs \(O(L^4)\) terms against \(O(L^5)\) for the full bispectrum.

In the paper's experiments, at \(L = 15\), a signal has 256 coefficients, the full bispectrum 1,124 stored entries and the selective one 380. At \(L = 64\) the selective one keeps 5,610. The fold-out compares the arithmetic as well, and the measured latencies come later.

Fold-out · skippableThree ratios at \(L = 64\)

At \(L = 64\), three ratios measure three different things. The full bispectrum stores 70,257 entries, which is 12.52 times the selective count. On a real signal, orderings of a triple of degrees are proportional and some entries vanish, so only 22,945 distinct nonzero entries remain, 4.09 times the selective count. At \(L = 15\) there are 352, fewer than the selective 380. In contraction terms, the full bispectrum sums 267,050,641 products and the selective one 10,837,962, a ratio of 24.64.

None of the theorems above covers the sphere. There, completeness for a generic real band-limited signal is a conjecture. It agrees with a dimension count, the rank of each degree's Jacobian, a parity entry and 32 reconstructions, but it is not proven.

Fold-out · skippableThe evidence on the sphere

A smooth complete invariant needs at least as many numbers as the orbits have dimensions. A digit kept as 256 coefficients with no rotational symmetry has a three-dimensional orbit, so the orbits form a space of 253 dimensions. The 380 values meet that bound, while max pooling over 8 rotations keeps 1 response out of 8 and the power spectrum 16 numbers. The count is necessary and not sufficient.

At random signals, the Jacobian of each degree's entries with respect to that degree's coefficients has full rank up to \(\ell = 100\), which shows local recovery of each degree with the lower degrees fixed. The odd-parity entry \(\beta_{2,3,4}\) changes sign under a mirror, so it detects a mirror image whenever it is nonzero. And the solver recovered all 32 test signals at \(L = 15\) up to a rotation, which is empirical evidence. None of these rules out a distant signal with the same invariants.

Experiment results

A fixed selective bispectrum layer followed by a small MLP comes within 0.3 points of two learned equivariant networks on rotated digits, and runs up to 300 times faster.

Accuracy on rotated digits

The paper tests this on Spherical MNIST (Cohen et al., 2018), the task of the classifiers at the top of this page, where every model trains on upright digits and is tested on rotated ones. Our model learns nothing before its head. It computes the 380 values of the augmented selective spherical bispectrum at \(L = 15\) and passes them to a three-layer MLP. It faces two equivariant networks of similar size, a spherical CNN and an e3nn tensor-product network, and two controls.

Our model lands 0.3 points behind both equivariant networks. The power spectrum control is just as invariant and stops at 77.7%, or 80.1% with an MLP 48 times larger, so the accuracy comes from what the bispectrum keeps, not from the head. The paper has the seeds, the significance tests and how each model fares with less training data.

Where the speed comes from

Both equivariant networks do group theory in every layer, while our model does it once, in a fixed layer without weights. Selectivity keeps the work of that layer proportional to the signal rather than to its square, and every Clebsch–Gordan table and Fourier kernel is precomputed, so on the sphere a forward pass reduces to a gather, a product and a scatter-add. On the GPU, each module records that pass as a CUDA graph and replays it as a single launch, which removes the launch overhead that dominates at small batch sizes.

Using the library

To install the library, simply run:

pip install bispectrum

Each group action is one torch.nn.Module without weights, named {Group}on{Domain}, that returns the selective bispectrum of a batch of signals. Here is the sphere module of the experiment above, checking that a rotation leaves its output unchanged: 

import torch
import torch.nn.functional as F
from bispectrum import SO3onS2
from bispectrum import random_rotation_matrix, rotate_spherical_function

bsp = SO3onS2(lmax=15, nlat=64, nlon=128)  # no weights, differentiable

# 16 smooth random signals on a 64 × 128 grid of the sphere
x = torch.randn(16, 1, 8, 16)
x = F.interpolate(x, size=(64, 128), mode='bicubic')[:, 0]
x_rot = rotate_spherical_function(x, random_rotation_matrix())

beta, beta_rot = bsp(x), bsp(x_rot)  # (16, 380), complex
err = (beta - beta_rot).abs().max() / beta.abs().max()
print(err)  # a few percent, the grid's resampling error

From there, beta can feed an MLP, as in the experiment, or stand in for max pooling inside an equivariant CNN, which the paper also tests. The README covers the other six modules.

Conclusion

The bispectrum is an exact invariant, complete for generic signals on finite groups, and its full form is quadratic in the size of the signal. Selective bispectra keep a number of entries linear in that size and stay complete on the commutative, dihedral and octahedral groups and on the disk. bispectrum computes them as one PyTorch module per group action. On rotated Spherical MNIST its features with an MLP come within 0.3 points of two equivariant networks, at 4 and 364 times lower latency. Issues and pull requests are welcome.

One question remains open. We conjecture that on the sphere, too, the selective bispectrum pins down almost every band-limited signal up to a rotation. Every test we ran agrees, but the proof is still missing. If you find one, or a counterexample, we would love to hear about it.
